# App Store Reviewer Note — Dialed Offroad v2.1.0 (build 34)

This release fixes the issue from the previous rejection (Guideline 2.1(a) —
Performance / App Completeness): the app froze on the splash screen on iPad.
Root cause was a navigation loop during cold-start routing that only manifested
on iPad: the launch resolver navigated to its own route on a fresh install,
which remounts the resolver on iPad and re-triggers the navigation
indefinitely, starving the JavaScript event loop so the splash screen never
dismissed. We fixed the resolver to never self-navigate, added an 8-second
startup watchdog that always dismisses the splash and lands the user in the
app, and wrapped every startup step so a failure degrades to a usable screen
rather than hanging. Verified fixed with a fresh install on iPad Air 11-inch
(M3) in Release configuration: the app reaches the onboarding screen within a
few seconds and CPU settles. This build also includes retention and
trial-experience improvements (trial status awareness, a win-back path for
lapsed subscribers, and onboarding copy refinements). No changes to account
requirements, pricing, or data handling.
