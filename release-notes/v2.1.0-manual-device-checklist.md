## A0 — iPad splash fix (CRITICAL, do first) — orig: fix/ipad-splash-hang
1. Fresh install on a physical iPad (or iPad Air 11-inch M3 sim), Release
   config. Cold start → onboarding "Stop guessing your suspension" appears
   within ~10s; splash does not hang; CPU settles to idle.
2. Force-quit and cold-start again several times → no hang on any launch.
3. Kill network (airplane mode), cold start → still reaches a usable screen
   within the 8s watchdog window (never a dead splash).
4. iPhone fresh install cold start → boots normally (no regression).

## Block A — Retention / decliner + security — orig: paywall-decliner-recovery (+ retention-loop-v1, security-day3)
A1. New user full funnel: signup → add bike → generate tune → decline paywall
    → force-quit → cold start lands on Home (NOT auto-presenting /premium),
    with the decliner unlock banner pinned at top.
A2. Tap the banner CTA → /premium presents the paywall. Tap banner body (tune
    still in 24h pending window) → blurred results screen.
A3. First-ride check-in: after a baseline exists and 12h+ pass, Home shows the
    ride check-in card ("How did the {bike} feel on v1?"). "Haven't ridden
    yet" snoozes (does NOT count toward the 2-dismissal cap); the ✕ does.
A4. Feedback→refine happy path saves; simulate a failed lineage write (airplane
    mode mid-submit) → toast appears, next cold start flushes the retry queue.
A5. Free-tune credit: generate once (consumes credit); a forced generation
    failure refunds it (trial_tunes_used returns to 0).
A6. Trial-modal timing: a decliner does NOT get the cold-start modal (banner
    owns Home); it fires once on first /bike-home visit that session.

## Block B — Trial experience (Day 4) + onboarding — orig: trial-experience-v1
B1. Day-2 value card: account 1–3 days old, in trial, with a tune → one-time
    Home card "Your {bike} is set up for YOU now"; ✕ dismisses permanently.
B2. Day-5 countdown: trial with ≤2 days left → countdown card "Your trial ends
    in N days" with real version/refinement counts + "Keep your setup dialed"
    → /premium. Subtle "Trial · N days left" hero line while >2 days remain.
    (Countdown always beats the value card — never both.)
B3. Trial reminder notification: with notifications already granted and
    auto-renew OFF, one local notification schedules for expiry−2d; enabling
    auto-renew or converting cancels it. Tapping it opens Home.
B4. Winback (lapsed subscriber): pro_until in the past → TrialPromptModal shows
    win-back copy and its CTA routes to /winback (annual-first offer). Setup
    History shows the list + stats strip but gates version detail/restore
    behind the winback CTA; a never-paid free user still hits the full gate.
B5. WS6 onboarding: all 4 slides render within one viewport on an SE-class
    phone (slide 2 may scroll gracefully); slide 2 shows the accent "Ride,
    rate, refine" 4th step; slide 4 shows annual-first pricing + "Cancel
    anytime in Settings" footer.
B6. WS5 recovery: re-signup with an existing email mid-funnel (e.g.
    results_locked) lands on the correct step, not past the paywall.
